# negacyclic-rings
Fast arithmetic for rings `Z_q[X]/(X^N + 1)`.
Provides const-generic 32-bit and 64-bit negacyclic NTT kernels.
Supports fixed-size multi-prime RNS with Garner reconstruction.
Includes parameter generation, correctness tests, benchmarks, and profiling targets.

All of the code is AI-generated and not audited (yet), for now only use this repository for educational purposes.
